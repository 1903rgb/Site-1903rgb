# Site 1903RGB

Site vitrine du studio web 1903RGB (Nancy) + 20 maquettes de démonstration.

- `src/page.html` : source de la page d'accueil (contenu + styles)
- `build.py` : génère `index.html` (site complet) et `_artifact.html` (aperçu claude.ai)
- `maquettes/<slug>/` : les 20 maquettes (accueil + page intérieure)
- `assets/` : vignettes, logo, vidéo de présentation
- `mentions-legales.html` : mentions légales

Hébergement : GitHub Pages (branche `main`, dossier racine). Formulaire de rendez-vous : Web3Forms vers 1903rgb@gmail.com.
